MetaCog — Brain Teasers
A lean brain-training website focused on short cognitive games.
Games
MetaCog currently has three games:
⚡ Speed Math
A fast arithmetic game where the player chooses a duration and solves addition, subtraction, and multiplication questions as quickly as possible.
- Instant answer detection — no Enter key required.
- Reaction time is measured silently and shown in the results.
- Questions are generated by the Flask backend.
- Local question generation is the default, so the game works without Gemini.
- Google Gemini can optionally generate questions with USE_GEMINI=true.
- If Gemini fails, the backend falls back to local generation.
🎨 Cognitive Clash
A Stroop-style cognitive test designed around reaction time, selective attention, and inhibitory control.
It has Easy, Medium, and Hard levels, with 7 questions per level, plus an option to play all three levels.
Cognitive Clash is frontend-only and does not require the Flask API.
🧠 Memory Grid
A visual memory game designed to measure memory performance rather than reaction speed.
The game progresses through 2×2, 3×3, 4×4, and 5×5 grids, with 3 questions for each grid size (12 questions per difficulty level).
It has Easy, Medium, and Hard levels. Difficulty increases through shorter memorization time, more emojis, and more demanding grid configurations.
The game uses an emoji pool including symbols such as 🗿 🍄 🔞 💀 🦄 ⚡ 👻 🍕 🚀 🐸 🌙 🔥 and includes protection against repeatedly generating very similar configurations.
At the end, it calculates a Memory IQ-style score from 70–130 based on performance and difficulty and keeps a personal best locally.
Memory Grid is completely independent of the backend API.
